# 🩺 Simulation-Based AI: Clinical Decision Support

An AI-driven system that uses **Causal-RAG** to assist healthcare professionals in diagnosing complex cases.

## 🚀 Key Features
* **Causal Methodology:** Maps symptoms to clinical literature using Llama 3.1.
* **Vector Intelligence:** Utilizes ChromaDB for high-precision retrieval.
* **Modern UI:** Streamlit interface optimized for clinical environments.

## 🛠️ Technical Stack
* **Language:** Python
* **LLM:** Llama 3.1 (Groq)
* **Vector DB:** ChromaDB
* **Frameworks:** FastAPI & Streamlit
